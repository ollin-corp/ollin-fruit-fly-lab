# M0 — Repository Genesis and Scientific Boundary Freeze

## Objective

Establish a minimal deterministic repository that can grow into a connectome laboratory without conflating source biology, model assumptions, or simulation results.

## Acceptance gates

- [x] universal ŌLLIN repository spine exists;
- [x] profile is explicitly selected;
- [x] project identity is machine-readable;
- [x] initial external datasets are version-pinned descriptors;
- [x] data/model/result separation is law;
- [x] bulk datasets are excluded from repository source;
- [x] scientific source registry exists;
- [x] deterministic local qualification exists;
- [x] next work is bounded to M1 ingestion/provenance.

## Out of scope

- bulk downloads;
- graph engine;
- neural dynamics;
- embodiment;
- learning;
- AI assistant behavior;
- Raspberry Pi runtime.
