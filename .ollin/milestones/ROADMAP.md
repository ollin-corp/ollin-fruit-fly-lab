# Initial Roadmap

This roadmap is directional. Each milestone requires its own bounded proposal/authorization before implementation.

- **M0** Repository genesis + scientific boundary freeze.
- **M1** Deterministic static-download manifest + importer for one FlyWire dataset.
- **M2** Normalized connectome schema + integrity validation.
- **M3** Graph engine + neuron/pathway queries.
- **M4** Graph experiments + lesion/ablation framework.
- **M5** Deterministic leaky-integrate-and-fire baseline.
- **M6** Published sensorimotor-model replication target.
- **M7** Sensory stimulus contract.
- **M8** Motor/descending-output contract.
- **M9** Closed-loop toy world.
- **M10** NeuroMechFly/FlyGym integration spike.
- **M11** Visual pathway experiments.
- **M12** Olfactory/gustatory experiments.
- **M13** Plasticity model boundary.
- **M14** Learning experiments.
- **M15** Whole-agent behavioral benchmark.
- **M16** Performance/GPU engine decision.
- **M17** Reduced edge runtime / FlyPi.
- **M18** Physical FlyBot interface.
- **M19** Hybrid FlyCore + language-model research interface.
- **M20** Reproducible experiment catalog and release qualification.
