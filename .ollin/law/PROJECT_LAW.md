# Project Law — M0

1. **Biology is source data, not permission to invent physiology.** Missing dynamical parameters must be explicit model assumptions.
2. **Dataset identity is immutable within an experiment.** Dataset name/version alone is insufficient after download; accepted artifacts require hashes.
3. **Raw external artifacts are read-only after acceptance.** Normalization produces derived artifacts rather than rewriting source files.
4. **No silent biological claims.** A software result must identify whether it is measured, source-annotated, inferred, modeled, trained, or experimentally observed in simulation.
5. **Reproducibility is mandatory.** Model version, data identity, configuration, code identity, and random seed (when applicable) belong to experiment evidence.
6. **Network access is not runtime authority.** Scientific downloads are explicit ingestion actions; core graph/simulation experiments must be able to run from accepted local artifacts.
7. **Third-party code/data licensing and citation requirements are preserved.** Nothing is vendored merely for convenience.
8. **No anthropomorphic equivalence claim.** A connectome-constrained simulation is not described as a complete biological mind or consciousness without evidence supporting that claim.
9. **Complexity is earned.** The repository begins Lite and promotes to Cells/Governed structure only when boundaries or risk justify it.
10. **AI is an engineering/research assistant, not scientific authority.** Claims require traceable source or experiment evidence.
